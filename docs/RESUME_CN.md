# 简历与面试表述（中文）

**项目名称：** 共享预算下的多 SKU 库存强化学习与安全决策平台

可直接放在简历的两条经历：

- 基于 M5 零售销售数据构建 64 SKU、共享采购预算与仓容约束的补货环境；实现可行订单分配、Double DQN 对照，以及以组合总回报为目标的情境化策略搜索 RL，并提供带模型摘要校验的 FastAPI 批量决策接口。
- 在两个预先固定的门店级留出回放中，分别训练的 RL 策略相较验证集调优补货规则使 WI_1 和 TX_3 的**离线模拟利润提升 1.51% 和 1.49%**；TX_3 使用 48 组规则候选的强基线，配对七日区块 bootstrap 95% 利润差区间为 +763.18 至 +6,993.33 模拟单位，满足率和日利润下十分位同步提高。公开早期负结果及冻结模型跨店迁移失败的结果。

**面试中应主动解释：** 这是离线模拟研究原型，并未接入企业 ERP。M5 提供历史销售而非真实未满足需求；成本、交货期、预算与仓容是模拟设定。WI_1 与 TX_3 是各自预先固定的门店级留出测试，策略分别训练，但共享同一段日历测试期；方法还曾参考其他门店测试反馈，不能宣称两次独立未来验证或一套模型跨店泛化。WI_1 的系数直接迁移到 WI_2、WI_3 时分别低于规则 1.21%。此前 Double DQN 和规则引导探索未过门禁，相关负结果也在仓库中。

**压力测试边界：** 在事后经济假设压力测试中，WI_1 的利润优势在采购预算降低 25% 或单位采购成本提高 25% 时翻负；TX_3 在这两种情况下点估计仍为正，但配对区间跨过零。主结果只适用于原始模拟经济设定，详见[完整压力测试](ECONOMICS_STRESS_RESULTS.md)。

**可展示的工程证据：** [逐日利润分解审计](ACCOUNTING_AUDIT.md)将 WI_1 和 TX_3 的利润差精确对账至收入、采购、持有和缺货罚金，并公开期末库存及在途订单；v4 接口强制核对 SKU 顺序、严格验证输入并返回模型/数据指纹，参见[接口契约](API_V4.md)。

**下一步：** 使用真实库存、缺货、价格与供应商交期记录校准模拟器；增加更多门店和时间原点，与 `(s,S)`、混合整数规划等运筹学方案比较；在影子模式中记录人工覆盖、漂移和服务水平，再考虑受控上线。
