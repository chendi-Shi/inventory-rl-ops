# 简历与面试表述（中文）

**项目名称：** 共享预算下的多 SKU 库存强化学习与安全决策平台

可直接放在简历的两条经历：

- 基于 M5 零售销售数据构建 64 SKU、共享采购预算与仓容约束的补货环境；实现贪心订单分配及精确动态规划对照、Double DQN 对照，以及以组合总回报为目标的情境化策略搜索 RL，并提供带模型摘要校验的 FastAPI 批量决策接口。
- 在两个预先固定的门店级留出回放中，分别训练的 RL 策略相较验证集调优补货规则使 WI_1 和 TX_3 的**离线模拟利润提升 1.51% 和 1.49%**；随后冻结模型、规则及 SKU 顺序，在新增 28 天日历期再回放，分别获得 **+3.16% 和 +1.56%** 的模拟利润点估计。公开 TX_3 新时期利润差区间跨零、两店日利润下十分位下降，以及早期 DQN 和跨店迁移失败结果。

**面试中应主动解释：** 这是离线模拟研究原型，并未接入企业 ERP。M5 提供历史销售而非真实未满足需求；成本、交货期、预算与仓容是模拟设定。WI_1 与 TX_3 原先各有预先固定的门店级留出测试，策略分别训练，但共享日历天 1801–1913；方法还曾参考其他门店测试反馈。新增的天 1914–1941 是对**原样冻结的两套策略**做的短期新日历回放，并非重新训练或真实前瞻业务试验。WI_1 的 +3.16% 对原规则配对七日区块区间为 +848.73 至 +4,406.71 模拟单位；TX_3 的 +1.56% 区间为 −740.04 至 +2,987.21，跨过零。两店新时期日利润下十分位均低于原规则，因此**都未满足原有发布门禁的下行保护条件**；模型包保持不变。不能宣称一套模型跨店泛化：WI_1 的系数直接迁移到 WI_2、WI_3 时分别低于规则 1.21%。详见[新增日历期结果](NEW_TIME_HOLDOUT_RESULTS.md)。

**更强规则的检验：** TX_3 新日历期的安全库存规则模拟利润为 63,223.45，RL 为 64,151.65，RL 点估计领先 **928.20（+1.47%）**；安全规则减 RL 的配对区间为 −2,978.25 至 +1,081.84，不能判定谁更好。该安全规则在旧 113 天回放中点估计比 RL 高 4,520.70，但设计于旧测试结果公开之后，属于事后分析，不能当作独立留出验证。见[安全库存比较](SAFETY_FUTURE_RESULTS.md)。

**精确分配器审计：** 新增多选背包动态规划，对每个决策时刻的 64 SKU、0/4/8/16 件选项，在共享约束内求策略分数总和的精确最优值，用于量化原贪心分配器的最优性差距。这是已检视的 1801–1941 天上的**事后诊断**，不是新的独立留出；两种分配器均从第 1801 天开始连续回放各自的库存路径。分数差距很小；在后 28 天，改用精确分配器的 RL 路径相对原分配器模拟利润分别为 WI_1 **−27.30**、TX_3 **−204.45**，两项配对区间均跨零，不能声称带来可靠利润提升，也没有据此提升模型版本或发布状态。当前各 SKU 单位成本和仓容占用相同，预算与仓容可合并为一个订货件数上限；若引入异质成本或体积，需使用多维约束求解。详见[精确分配器结果](EXACT_ALLOCATOR_RESULTS.md)。复现命令：

```bash
inventory-rl m5-allocator-audit --validation data/m5/sales_train_validation.csv \
  --evaluation data/m5/sales_train_evaluation.csv \
  --output artifacts/m5-allocator-audit
```

**压力测试边界：** 在事后经济假设压力测试中，WI_1 的利润优势在采购预算降低 25% 或单位采购成本提高 25% 时翻负；TX_3 在这两种情况下点估计仍为正，但配对区间跨过零。主结果只适用于原始模拟经济设定，详见[完整压力测试](ECONOMICS_STRESS_RESULTS.md)。

**可展示的工程证据：** [逐日利润分解审计](ACCOUNTING_AUDIT.md)将 WI_1 和 TX_3 的利润差精确对账至收入、采购、持有和缺货罚金，并公开期末库存及在途订单；[精确分配器审计](EXACT_ALLOCATOR_RESULTS.md)用可验证的最优分数界限检查贪心分配；v4 接口强制核对 SKU 顺序、严格验证输入并返回模型/数据指纹，参见[接口契约](API_V4.md)。

**下一步：** 使用真实库存、缺货、价格与供应商交期记录校准模拟器；补充更长的新时间期及更多门店，与 `(s,S)`、多期随机规划等完整补货方案比较；调查新时期下行日利润下降的原因，在影子模式中记录人工覆盖、漂移和服务水平，再考虑受控上线。
