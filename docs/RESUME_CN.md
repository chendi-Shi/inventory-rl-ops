# 简历与面试表述（中文）

**项目名称：** 共享预算下的多 SKU 库存强化学习与安全决策平台

可直接放在简历的两条经历：

- 基于 M5 零售销售数据构建 64 SKU、共享采购预算与仓容约束的补货环境；实现可行订单分配、Double DQN 对照，以及以组合总回报为目标的情境化策略搜索 RL，并提供带模型摘要校验的 FastAPI 批量决策接口。
- 在预先固定的 WI_1 门店测试期，策略搜索 RL 相比验证集调优的补货规则使**模拟利润提升 1.51%**（+4,590.80 模拟单位；配对 95% 区间 +805.82 至 +8,490.15），同时提高满足率和日利润下十分位；上线门禁通过。公开失败的早期 RL 实验及 WI_2/WI_3 冻结模型跨店复验结果，避免将单店结果夸大为普适收益。

**面试中应主动解释：** 这是离线模拟研究原型，并未接入企业 ERP。M5 提供历史销售而非真实未满足需求；成本、交货期、预算与仓容是模拟设定。WI_1 是新方法的预先固定独立测试，较强的事后规则敏感性检查仍显示约 1.50% 的模拟利润差，但它不是第二次独立验证。WI_1 的系数直接迁移到 WI_2、WI_3 时分别低于规则 1.21%，所以不能宣称跨门店普遍改善。此前 Double DQN 和规则引导探索未过门禁，相关负结果也在仓库中。

**下一步：** 使用真实库存、缺货、价格与供应商交期记录校准模拟器；增加更多门店和时间原点，与 `(s,S)`、混合整数规划等运筹学方案比较；在影子模式中记录人工覆盖、漂移和服务水平，再考虑受控上线。

可以写“在 WI_1 离线模拟中，RL 相比验证集调优规则提升 1.51% 模拟利润”；不要删掉“WI_1”“离线模拟”或写成实际业务利润。证据见 [WI_1 预先固定测试](PORTFOLIO_POLICY_SEARCH_RESULTS.md)、[更强基线的事后检查](STRONGER_BASELINE_SENSITIVITY.md)、[WI_2/WI_3 迁移失败](TRANSFER_RESULTS.md)和各自机器可读报告。
